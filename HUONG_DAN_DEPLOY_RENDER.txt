COPY ĐÈ / THÊM:

- lib/auth.js
- package.json
- render.yaml
- .env.production.example

TRIỂN KHAI:
1. Copy các file trên vào dự án chính.
2. Đẩy dự án lên GitHub. Không đưa lên GitHub:
   .env, private/, backups/, node_modules/
3. Render -> New -> Blueprint -> chọn repository và render.yaml.
4. Nhập các biến được hỏi:
   PHF_PUBLIC_URL
   SUPABASE_URL
   SUPABASE_SECRET_KEY
   PHF_BOOTSTRAP_ADMIN_EMAIL
   PHF_BOOTSTRAP_ADMIN_PASSWORD
5. Mở URL Render + /api/health. Kết quả phải có ok=true.
6. Đăng nhập bằng Admin khởi tạo ở bước 4.
7. Vào Quản trị -> Tài khoản để tạo/đồng bộ tài khoản chính thức.
8. Render -> Settings -> Custom Domains:
   thêm training.phuhoafresh.info.vn
9. Đổi DNS theo giá trị Render cung cấp. Chỉ gỡ domain khỏi Vercel sau khi Render báo Verified.

QUAN TRỌNG:
- Cấu trúc tài khoản hiện tại lưu file accounts.json, nên cần persistent disk.
- Không dùng tài khoản admin.test@phf.local / 123456 trên production.
- Bản này chuẩn bị code deploy; kết nối GitHub, nhập secret và đổi DNS vẫn phải thao tác trên tài khoản Render/DNS của anh.
